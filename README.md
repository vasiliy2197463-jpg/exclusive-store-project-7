# Exclusive Store — проект №7

Адаптивный интернет-магазин на Next.js 14 и Supabase. Реализованы регистрация и вход, профиль покупателя, корзина, оформление заказа без онлайн-оплаты и административная панель для управления товарами, остатками, заказами, клиентами и обращениями.

## Локальный запуск

1. Скопируйте `.env.example` в `.env.local` и заполните переменные Supabase.
2. Выполните `npm install`.
3. Запустите `npm run dev`.

## База данных

Выполните SQL-файлы из `supabase/migrations` по порядку. Локальные ключи и `.env.local` не публикуются в Git.

## Публикация

Проект использует серверные маршруты Next.js, поэтому код хранится на GitHub, а сайт разворачивается на Vercel или другом Node.js-хостинге. После публикации добавьте публичный домен в Supabase Authentication → URL Configuration как Site URL и Redirect URL.
